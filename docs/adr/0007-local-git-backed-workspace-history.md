# Each Workspace uses local Git-backed history

Every Workspace is initialized as a fresh dedicated local Git repository so human edits, Ingest Runs, and recovery share one history. CorpusBot does not reuse an existing repository at the selected root, although the Workspace itself may be nested inside an enclosing repository. Only `wiki/`, `raw/`, and the Workspace `.gitignore` belong to CorpusBot's snapshot and restore scope; other files in the root remain untouched. Tracked `wiki/` and `raw/` content must be clean and explicitly captured before the apply phase; a successful Ingest commits its result, while a failed or interrupted apply is recovered before further mutations. The MVP deliberately excludes remote operations, branch merges, and automatic conflict resolution; external Git clients may remain in use, but CorpusBot will refuse unsafe states such as merge or rebase.
